Proyecto Libro de clases

Este pequeño proyecto pretende hacer el trabajo de un libro de clases online haciendo el trabajo de registrar alumnos recien llegados a un curso el cual mas tarde permitira mostrar un listado de todos los alumnos inscritos.

El programa se asegura de pedir primeramente el iniciar una sesion la cual vendria siendo el
login de un teorico profesor (aqui mismo dejare las credenciales necesarias).
